# Display typography

Bodoni Moda by Owen Earl / the Bodoni Moda Project Authors. The unchanged variable
font is bundled for offline TV rendering of the welcome, home time and landscape clock.

- Source: https://github.com/google/fonts/tree/main/ofl/bodonimoda
- Upstream: https://github.com/indestructible-type/Bodoni
- License: SIL Open Font License 1.1, included as `BodoniModa-OFL.txt`.
- SHA-256: `550f5e34ee0a828d7941b1fe9bc58b34e5260d3f33a61532e6d0a0114e79a5cf`

No font or photo is downloaded by the TV at runtime.
